# 쇼핑쇼츠 스튜디오 다운로드

상품 영상을 넣으면 장면 분석·대본·자막·내레이션까지 자동으로 만들어 주는 쇼핑 쇼츠 제작 프로그램입니다.

## 설치 방법

1. 오른쪽 **Releases** → 최신 버전의 `ShortsStudio_Setup_버전.exe` 를 받습니다.
2. 받은 파일을 실행합니다.
   - **"Windows의 PC 보호"** 파란 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. (새 프로그램이라 뜨는 안내예요)
3. 설치가 끝나면 바탕화면의 **쇼핑쇼츠 스튜디오** 를 실행합니다.
4. 이용약관에 동의하고 **이용 코드**를 넣거나 **7일 무료 체험**을 시작하세요.

## 사용 환경

- Windows 10 / 11 (64비트)
- 구글 크롬 설치 필요
- 메모리 16GB 이상 권장, 여유 공간 10GB 이상
- (권장) NVIDIA 그래픽카드 — 없어도 되지만 영상 만들기가 느려요

이용 코드가 있어야 사용할 수 있습니다.
